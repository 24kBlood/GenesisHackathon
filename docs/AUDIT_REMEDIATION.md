# Проверки закрытого запуска

## Допуск эпизода к оценке

Координатор проверяет ссылки и публичные доказательства, лимиты подачи и возможность сопоставить все эталонные ошибки один к одному. Проверка выполняется до запуска политики. Oracle используется только в доверенном контуре. [Допуск эпизода](../src/genesis/evaluation/admission.py) · [Подготовка закрытого прогона](ISOLATION_AND_LEAKAGE.md#создание-закрытого-эпизода)

## Запуск и завершение контейнера

Координатор ждёт отметку Docker о старте контейнера, прежде чем передать ему наблюдения. Сбой на этапе подготовки прерывает запуск без оценки. Если Docker подтвердил запуск, последующий выход политики обрабатывается по контракту транспорта. Для оценивания также требуется подтверждённое удаление контейнера. [Изоляция](ISOLATION_AND_LEAKAGE.md) · [Проверки запуска и завершения](../tests/test_audit_remediation.py)

## Публикация траектории

`run-policy --trace` сохраняет журнал атомарно в новый файл на файловой системе с поддержкой жёстких ссылок. При ошибке записи готовая оценка остаётся в JSON по stdout. Статус сохранения находится в поле `trace`, сообщение об ошибке — в stderr. [Запуск политики](BASELINE_POLICIES.md#запуск-и-контейнер-политики)
