# Сопоставление выводов

Алгоритм [ADR 0003](ADR/0003-matching-and-reward.md) реализован в `genesis.evaluation.matcher.match`. На вход передаются прошедшие проверку схемы списки выводов и эталонных ошибок одного эпизода, а также каталог ID его открытых доказательств. Результат содержит пары «индекс вывода, ID ошибки», индексы ложных выводов, ID пропущенных ошибок и счётчики `tp`, `fp`, `fn`.

По умолчанию ожидаемая и заявленная суммы совпадают до минимальной единицы валюты. При необходимости оценщик передаёт явно опубликованный набор допусков `tolerances_minor` по типам ошибок. Граница допуска включительна. Валюты должны совпадать при любом допуске.

Сопоставление использует поиск увеличивающих путей. Поэтому оно сохраняет максимальное число пар и в случае, когда два вывода допускают совпадение с одной ошибкой, а один из них допускает совпадение ещё с другой. Группировка повторов ограничивает их одним TP. Доказательства сравниваются отдельно для каждого вывода группы.

Детальные пары содержат закрытые ID ошибок и остаются у оценщика. Правила метрик и терминальной награды зафиксированы в [ADR 0003](ADR/0003-matching-and-reward.md#метрики-и-возврат).

Доверенная фабрика вызывает `genesis.environment.episode.build_episode` с открытыми таблицами, manifest, политикой и эталоном того же эпизода. Для доступа к записям и проверки доказательств используется один каталог. Фабрика фиксирует активный опубликованный набор допусков при сборке эпизода.

На завершении координатор читает `AuditorEnv.terminal_result`. В доверенном результате доступны пары и счётчики TP/FP/FN, точность, полнота, F1, возврат, число исследовательских и всех действий, причина завершения и время по монотонным часам. Отсчёт начинается после подготовки первого наблюдения и заканчивается при фиксации завершения. Время сопоставления в него не входит. В режиме `eval` чтение результата происходит после передачи политике нейтрального подтверждения с нулевой наградой.

Из корня репозитория на Python 3.11:

```sh
PYTHONPATH=src python -m unittest discover -s tests -p test_matcher.py -v
PYTHONPATH=src python -m unittest discover -s tests -p test_terminal_integration.py -v
```
