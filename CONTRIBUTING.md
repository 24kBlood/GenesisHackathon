# Как работать над проектом

1. Возьмите задачу из [GitHub Issues](https://github.com/24kBlood/GenesisHackathon/issues), проверьте зависимости и согласуйте границы с архитектором.
2. Обновите базу командой `git fetch origin`. Создайте собственную ветку `git switch -c draft/<номер>-<slug> origin/main`. Для работы с зависимым Draft PR явно укажите его как базу и запишите зависимость в задаче.
3. Измените файлы из задачи, добавьте проверки нового поведения и запишите их команды и результаты.
4. Отправьте ветку `git push -u origin HEAD`. Откройте Draft PR со ссылкой `Closes #<номер>`, заполните [шаблон PR](.github/PULL_REQUEST_TEMPLATE.md).
5. QA повторяет проверки и сохраняет результаты. Ревьюер проверяет контракт, данные, награду, воспроизводимость и границы оценщика. Архитектор принимает решение о готовности PR. Merge выполняет капитан после явного согласования.

Прямые push в `main`, `master`, `develop` и force-push запрещены правилами команды. Параметры защиты меняет администратор по решению капитана. Требуемый режим для `main` включает PR, минимум одно одобрение, успешный CI и запрет прямых и принудительных push.

## Роли и доказательства

| Роль | Ответственность |
| --- | --- |
| Архитектор | Формулирует решение и ADR, критерии приёмки и зависимости, принимает результат ревью. |
| Инженер | Готовит минимальный инкремент в отдельной ветке, тесты и Draft PR. |
| QA | Фиксирует команды, результаты и ограничения проверок, повторяет прогоны на одинаковых эпизодах. |
| Ревьюер | Проверяет изменение по требованиям кейса и оставляет конкретные замечания. |
| Docs / DevOps | Поддерживает инструкции запуска, офлайн-проверку и автоматизацию CI. |
| Аудитор изоляции | Проверяет границы процесса оценщика и отсутствие закрытого эталона в наблюдениях и траекториях. |

При сообщении об ошибке укажите открытый seed, конфигурацию, действия и наблюдаемый результат. Закрытые конфигурации, закрытый эталон и секреты не включаются в задачи, PR и логи агента. Порядок работы с задачами описан в [справочнике меток](.github/LABELS.md).
